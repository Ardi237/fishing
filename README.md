# Simulasi Analisis Biaya Asuransi Kesehatan

Aplikasi Streamlit interaktif untuk menjelaskan alur pengelolaan dan analisis data biaya asuransi kesehatan, mulai dari pengumpulan data sampai visualisasi. Proyek ini berfokus pada statistika deskriptif dan tidak menggunakan machine learning.

## Menjalankan aplikasi

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

Versi notebook yang siap diunggah ke Google Colab tersedia di `Simulasi_Streamlit_Alur_Tugas_Statistika.ipynb`.
